# 视频/07 声音与音频立法（视频轨）

声音是提示词里最常被**整段省略**的维度——模型默认会自行配乐、配音、加音效，失控方式是"突然冒出背景音乐"或"口型对不上"。官方与高赞项目的共同解法：**音频单独成块立法**，写清"要什么声、不要什么声、什么节拍出什么声"。核心三句：**Diegetic sound only（只写剧情内声源）→ 逐节拍声音时间轴 → 否定清单封闭收尾**。

## 一、音频块命名形态学 [实测 S25]

同一功能四个块名并存（无官方统一标准，块名自创但功能一致）：

| 块名 | 出处 | 形态 |
|---|---|---|
| `AUDIO` | the-new-girl/otto/a-life/one-more-time（十块结构标配） | 独立块，4-15 行 |
| `SOUND` | SEED_AUDIO_1_0_LAUNCH_VIDEO（官方音频模型发布片）×285；sitara（声学画像）×128 | 独立块或冒号行 |
| `VOICES` | SOUL_ANGEL（soul 团队） | 口音专块，逐音素立法 |
| `Audio:` | chandler 广告规格头 / planet-47 尾行 | 一行冒号简式 |
| `AUDIO RESTRICTIONS:` | petya ×98 | 纯禁令清单块 |

**强度阶梯**（按场景复杂度选择）：一行简式（`Audio: no background music.`）→ 十一行规格头中的一行 → 独立块 4-15 行 → 超密度逐节拍清单（a-life AUDIO×414，全项目块频超 CAMERA）。

## 二、封闭式音频否定族 [案例 a-life 原文]

```
AUDIO

Diegetic sound only.

NO MUSIC.
NO SCORE.
NO DIALOGUE.
```
（对白在别处立法时，音频块内也重复 NO DIALOGUE——双保险）

块尾封闭句：
```
Nothing else.
```
[案例 a-life 41,466c]——音频清单结束后一句"没有别的"，禁止模型自由发挥。这是音频版的"封闭世界假设"。

简式同族否定 [案例 chandler]：`Audio: Environmental SFX only. No music. No subtitles — except the end card text specified in CUT 3, which is a deliberate on-screen title.`——例外必须与禁令同句写明，否则模型一并禁掉。

## 三、声音节拍时间轴 [案例 a-life AUDIO×414]

声音不整段总述，**按剧情节拍逐段列清单**（分号分隔，节拍标题独立成行）：

```
Beginning:
water moving inside <<<bathtub>>>;
Earl's controlled exertion;
fabric dragging through water;
small galvanized metal resonance;
Earl's shoes subtly shifting against rough stone.

As Earl pulls:
water displacement grows;
wet clothes drag;
Earl exhales through effort.

When Valentina's face clears:
water drains from <<<towel>>.

...

Earl begins crying first.
Approximately one second later:
Valentina's first broken sob.

During hug:
wet fabric compresses;
Valentina's muffled crying;
...

Nothing else.
```

**立法要点**：
1. 声源具体到物件与材质（galvanized metal resonance / rough stone）——与生图轨"质感=材质名"同源
2. 声音与动作严格对齐（When Valentina's face clears: water drains…）——声画同步立法
3. **谁先发声也立法**（Earl begins crying first. Approximately one second later: Valentina's first broken sob.）——情感时序精确到秒
4. 每节拍 3-5 个声源，全部剧情内（diegetic）

## 四、氛围床与低频垫底 [官方 SEED_AUDIO 发布片 5,426c 全文逐字]

```
SOUND: diegetic only, no music score, no narrator. Continuous jungle ambience bed
(insects, distant birds, dripping foliage). A low panther growl builds from 0:00
and stays low and sustained beneath the dialogue.
```

- **氛围床（ambience bed）**：连续环境层（三例声源括号列举）——对话场景的声音底座
- **低频威胁垫底**：`builds from 0:00 and stays low and sustained beneath the dialogue`——威胁声从第 0 秒建立、持续垫在对白之下、不抢频段；危险感靠声音持续性而非音量
- 配套表演立法：`Nobody smiles — each face carries suppressed fear beneath broadcast composure.`（声音威胁→面部压抑，声演一致）

## 五、唇同步正面律 [官方 SEED_AUDIO]

**正面构图 = 唇同步质量前提**。侧脸/遮挡嘴部 → 唇同步失败：

```
Both lines are on-camera spoken dialogue, each delivered while its speaker is
framed frontally, never in profile.
```

否定栈三连 [官方 SEED_AUDIO negative]：
```
lip-sync on profile faces, lip-sync drift, leaf occluding the mouth during dialogue
```
——转场用的前景遮挡（香蕉叶扫过全帧）也被禁遮嘴：**转场可以遮镜头，不能遮嘴**。

对白台词逐字嵌入 [案例 the-new-girl POSITIVE LOCKS]：
```
Haruka SPEAKS ALOUD with accurate lip-sync — first a playful, intrigued "ふーん…",
then a 2-second beat as her eyes travel up the tall stack, then a reluctant, unsure,
half-groaning "えぇ…こんなに持てるかな…"
```
——非英语台词直接写原文（日语），语气描述逐段标注；台词间的停顿（a 2-second beat）也是立法对象。

## 六、180 度轴线立法 [官方 SEED_AUDIO]

对话场景空间连续性的成文形态（全库首见）：

```
180-degree line held: the panther is downstage on the camera side, the two
broadcasters face toward it.
```

写法=声明轴线保持 + 交代各方在轴线的哪一侧（谁在镜头侧/谁面向谁）。多主体对话（2 人以上）加一线即可防止跨轴跳切感。

## 七、活体微动律 [官方 SEED_AUDIO]

静态机位防止"冻结感"：

```
The camera holds frontal on each speaker during their line for clean lip-sync but
never fully locks off — a faint breathing micro-motion stays alive on the face so
it never freezes into a still.
```

- 与 视频/03"呼吸手持"同族但更细：**机位不动 ≠ 画面死**，面部保留呼吸微动
- 配套否定：`flicker, morphing, teleporting subjects`

## 八、VOICES 口音逐音素块 [案例 SOUL_ANGEL（S16 前批证据）]

soul 团队对白项目的声音专块——口音立法精确到音素层面：

```
VOICES
French accent: r's softened and made at the back of the throat, "th" leaning
toward a soft "z"
```

逐角色口音描述（每个 VOICE 一段）：不只写 accent 名，写**发音动作**（r 在喉后软化、th 偏向 z）——给模型可执行的发音行为描述而非标签。

## 九、音频立法反模式

| 反模式 | 后果 | 替代 |
|---|---|---|
| 不写音频块 | 模型自加配乐 | 哪怕一行 `Audio: no background music.` |
| 写 "beautiful music" 类情绪标签 | 配乐风格不可控 | 声源清单（剧情内声源逐个列）|
| 情绪变化只写视觉 | 声音不跟随情绪 | 声音节拍时间轴逐段立法 |
| 对白用英语转写非英语台词 | 口型/发音失真 | 台词原文逐字嵌入（ふーん…）|
| 侧脸说话构图 | 唇同步失败 | 唇同步正面律 + negative 栈三连 |
| 只写"紧张的音乐" | 抢对白频段 | 氛围床 + 低频垫底 beneath the dialogue |
| 静态机位下完全锁死 | 画面冻结成静帧 | 活体微动律 |

### 7. 音频立法六层谱系与两极 LOCK [案例 S30 where-letters-fall 同项目两块并存]

**六层谱系**（由弱到强）：无音频块 → 一行简式（`Audio: no background music.`）→ AUDIO 块 → 禁令清单（AUDIO RESTRICTIONS 11 连）→ **EXCLUSIVE AUDIO LOCK 独占锁** → **COMPLETE SOUNDTRACK LOCK 完整重制锁**。

**独占音频锁**（无配乐封闭型）：
```
EXCLUSIVE AUDIO LOCK
The entire soundtrack consists solely of the specified door movement, porch contacts and creaks...
Every sound follows its physical source, timing, distance, and intensity. Use only these sounds,
with natural pauses between individual events. Maintain their spatial continuity and restrained
levels through the final frame.
```

**完整配乐锁**（重制型——与 NO MUSIC 相反极）：
```
COMPLETE SOUNDTRACK LOCK
Create every sound as a new synchronized recording for this scene. <<<video_2>>> guides Betsy's
vocal identity only. <<<video_3>>> guides forest appearance only. Neither reference contributes
recorded audio.
```
